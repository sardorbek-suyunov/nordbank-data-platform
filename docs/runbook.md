# Runbook

Operational procedures for running the platform locally. Prerequisites: Python 3.11, uv,
Docker Desktop, GNU make, and on Windows a Git Bash shell with make on the PATH, because the
Makefile recipes run under bash.

## Local setup

Populated at M1, when there is a stack to start.

## Service endpoints

Populated at M1, when the services exist and their ports are fixed.

## Common failures

Populated at M4, when the first ingestion DAGs can fail in ways worth writing down.

## Backfill procedure

Populated at M4, once partitions, batch ids and watermarks are in place.

## Escalation

Populated at M7, together with the data quality gates and the ops observability model.
