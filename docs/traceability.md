# Traceability

One row for every column named in [metric_definitions.md](metric_definitions.md) and
[model_inventory.md](model_inventory.md), mapped to the source column that supplies it or
marked as derived with the layer that derives it.

The point of the exercise is that an unsupplied reference is a defect in this milestone rather
than a note for later. Eleven references could not be supplied from the schema as specified;
each is resolved below and in the amendments those documents carry.

`_sk` columns are surrogate keys hashed from a business key in gold (conventions.md) and never
come from the source. `_eur` columns are converted in silver from the transaction amount and
the FX rate, which is an external feed rather than a core banking entity.

## Two resolutions with no column of their own

| Reference | Resolution |
|---|---|
| `transactions.direction` | **Not a column of `core.transactions`.** Direction is a property of the transaction type and lives on `ref.transaction_types.direction`; the transaction reaches it through the foreign key. Storing it in both places would let the two disagree. Spec 002 section 3 records the same |
| `gl_accounts` normal balance side | **Not a column of `ref.gl_accounts`.** The normal side is a function of the account type: asset and expense are debit, liability, equity and income are credit. It lives on `ref.gl_account_types.normal_side_code`, and `gl_accounts` reaches it through the foreign key, for the same reason |

## Gap 8 and gap 11, which are model inventory defects rather than missing columns

| Gap | Resolution |
|---|---|
| `dim_detection_rule` read `sl_fraud_alerts` | A dimension built from alerts cannot see a rule that never fired. It reads `sl_fraud_rules`, which is added to `model_inventory.md` |
| The coverage rule and 28 reference tables | No `ref` table is exempt. Each either becomes a conformed dimension in its own right or is consumed as attributes of one, and each is named in `data_dictionary.md` with the dimension that consumes it. None needs a silver model of its own |
