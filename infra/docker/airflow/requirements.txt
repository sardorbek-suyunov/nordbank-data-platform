# Runtime dependencies for the project Airflow image.
#
# pyarrow, boto3, psycopg2-binary and requests are resolved against the official Airflow
# constraints file for the pinned version, so their versions come from there.
#
# duckdb is not in the constraints file, and is not pinned here: it is pinned once, in
# pyproject.toml's `warehouse` group, and installed from requirements-warehouse.txt, which is
# exported from the lock (scripts/requirements_export.py, checked in CI).
#
# apache-airflow-providers-fab is required by the auth manager configured in compose. The build
# verifies it imports rather than assuming the base image carries it.
#
# pytest is present so that DAG integrity tests can run inside this image on hosts where
# Airflow does not import natively.
pyarrow
boto3
psycopg2-binary
requests
apache-airflow-providers-fab
pytest
